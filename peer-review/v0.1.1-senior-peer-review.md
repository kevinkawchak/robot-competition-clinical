## Recommended Code Fixes (for Claude implementation)

> Note: This document intentionally does not apply code edits directly; it specifies targeted fixes to implement.

### Critical / High Priority

1. **Validate `fps` inputs in both Python CLIs.**  
   - Files: `simulation/run_simulation.py`, `simulation/export_animation.py`  
   - Problem: `fps <= 0` causes division-by-zero and invalid frame scheduling.  
   - Fix: enforce `fps >= 1` at CLI parse time and in function-level guards; return user-friendly errors.

2. **Guard site ID lookups before indexing `data.site_xpos`.**  
   - File: `simulation/run_simulation.py`  
   - Problem: `mj_name2id(...)` may return `-1`; indexing with `-1` silently reads the wrong site, corrupting metrics.  
   - Fix: resolve site IDs once before loop; if missing, fail fast with explicit error.

3. **Include terminal frame deterministically.**  
   - File: `simulation/run_simulation.py`  
   - Problem: `steps = int(TOTAL_DURATION / timestep)` truncates final fractional step and may omit end-of-phase frame.  
   - Fix: use `math.ceil(...)` and/or explicit final-frame capture at `TOTAL_DURATION`.

4. **Replace broad exception handling around viewer launch with narrower handling.**  
   - File: `simulation/run_simulation.py`  
   - Problem: blanket `except Exception` can hide coding/runtime defects.  
   - Fix: catch known viewer/display exceptions; re-raise unexpected exceptions.

### Medium Priority

5. **Precompute MuJoCo object IDs outside simulation loop.**  
   - File: `simulation/run_simulation.py`  
   - Problem: repeated `mj_name2id` calls in-frame add avoidable overhead.  
   - Fix: cache IDs before stepping and reuse.

6. **Add type-safe structured return models for simulation payloads.**  
   - Files: `simulation/run_simulation.py`, `simulation/export_animation.py`  
   - Problem: untyped dict payloads are error-prone during schema evolution.  
   - Fix: introduce `TypedDict`/dataclasses for frame and result contracts.

7. **Use explicit encoding for file I/O and consistent JSON formatting policy.**  
   - Files: `simulation/run_simulation.py`, `simulation/export_animation.py`  
   - Problem: implicit encoding and mixed JSON style (pretty vs minified) complicate diffs and portability.  
   - Fix: use `encoding="utf-8"`; define one formatting standard (or configurable pretty/minified mode).

8. **Centralize duplicated phase/timing constants.**  
   - Files: `simulation/run_simulation.py`, `simulation/export_animation.py`  
   - Problem: duplicated phase values can drift and desynchronize backend/export behavior.  
   - Fix: single shared constants module imported by both scripts.

9. **Add schema-version compatibility checks in web loader path.**  
   - File: `docs/index.html`  
   - Problem: viewer can fail ambiguously if JSON shape changes.  
   - Fix: validate `version`, required keys, and emit clear UI errors.

10. **Reduce monolithic `docs/index.html` by modularizing JS.**  
    - File: `docs/index.html`  
    - Problem: maintainability and reviewability degrade in single-file mega-script.  
    - Fix: split into modules (`scene`, `actors`, `animation`, `ui`, `io`) and bundle or use ESM.

### Low Priority / Hygiene

11. **Expand CI beyond lint/format checks.**  
    - File: `.github/workflows/ci.yml`  
    - Problem: no automated runtime regression detection.  
    - Fix: add smoke tests for `--fps` boundaries, export generation, and JSON schema validation.

12. **Document hardware/runtime requirements consistently.**  
    - Files: `README.md`, `releases.md`  
    - Problem: narrative mixes broad compatibility claims with backend GPU wording; readers may misinterpret requirements.  
    - Fix: explicitly separate "web viewer requirements" vs "optional MuJoCo backend requirements".

13. **Add baseline unit tests for motion-phase transitions and interpolation monotonicity.**  
    - Files to add under `tests/`  
    - Problem: core motion logic currently untested.  
    - Fix: test `get_current_phase`, interpolation bounds, and phase continuity.

14. **Add pre-commit configuration for local consistency.**  
    - Files to add: `.pre-commit-config.yaml`  
    - Problem: no local automation for lint/format before push.  
    - Fix: configure `ruff` hooks to align local and CI standards.
