## Recommended Code Fixes (for Claude)

> This document intentionally does **not** modify source code. It specifies concrete fixes for a follow-up implementation PR.

### High Priority

1. **Resolve GitHub Pages path portability for both viewers (root + `/v2/`).**  
   - Files: `docs/index.html`, `docs/v2/index.html`, `README.md`  
   - Issue: users can easily land in one viewer directory without clear navigation to the other; URLs are documented with hard-coded repo assumptions.  
   - Fix:
     - Add a small, shared navigation banner in both HTML files with links to both viewers.
     - Generate links from `window.location.pathname` (base-path aware) instead of hard-coded absolute paths.
     - In README, document both relative paths (`/` and `/v2/`) and fork-safe URL guidance.
   - Acceptance criteria:
     - Root viewer can jump to v2.
     - v2 viewer can jump back to root.
     - Works for forks and non-default GitHub Pages base paths.

2. **Fix payload versioning inconsistency in v2 export/results.**  
   - File: `simulation_v2/run_competition.py`  
   - Issue: output embeds `"version": "2.0.0"` while project release stream is `v0.2.x`, which can confuse clients and release tooling.
   - Fix: align version value to project semantic stream (e.g., `0.2.1`) or rename key to `schema_version` and maintain separately.

3. **Ensure exported animation includes explicit terminal frame at exact duration.**  
   - File: `simulation/export_animation.py`  
   - Issue: frame generation uses `ceil(duration * fps)` and may omit a final keyframe exactly at `TOTAL_DURATION`.
   - Fix: append deterministic final keyframe at `t = TOTAL_DURATION` when missing (same approach already used in `simulation/run_simulation.py`).

### Medium Priority

4. **Tighten typing for `CompetitionResult.ppo_config`.**  
   - File: `simulation_v2/constants.py`  
   - Issue: current type is `dict[str, float]`, but runtime payload includes string values (e.g., architecture).  
   - Fix: define a dedicated `TypedDict` for PPO config fields with proper mixed types.

5. **Add JSON schema validation in web loaders before runtime use.**  
   - Files: `docs/index.html`, `docs/v2/index.html`  
   - Issue: upload parsing accepts JSON but does not clearly validate schema version/required fields before usage.  
   - Fix: validate required keys and show actionable UI errors.

6. **Add parity tests for exported payload boundaries.**  
   - Files to add: `tests/test_exports.py`  
   - Issue: tests cover phase math and competition metrics, but not output payload boundary guarantees.  
   - Fix: test exact final timestamp presence, non-empty phase arrays, and version/schema fields.

7. **Refactor monolithic viewer scripts into modules.**  
   - Files: `docs/index.html`, `docs/v2/index.html`  
   - Issue: large inline scripts slow review/maintenance.
   - Fix: split into `scene`, `ui`, `animation`, `io`, `scoring` modules under `docs/js/`.

8. **Standardize release metadata references.**  
   - Files: `README.md`, `releases.md`, `changelog.md`  
   - Issue: docs mix project version, simulation version, and schema version language.
   - Fix: document naming policy (`project_version`, `schema_version`, `viewer_version`) and apply consistently.

### Low Priority

9. **Add lightweight smoke command docs for contributors.**  
   - File: `README.md`  
   - Fix: include one section with `pytest -q`, `ruff check .`, and optional export commands.

10. **Add a compact architecture map for v2 viewer internals.**  
   - File to add: `docs/diagrams/v2_viewer_modules.md`  
   - Fix: one-page module dependency map to reduce onboarding time.

## GitHub Pages Issue Resolution Plan (Implementation Blueprint)

To make either simulation runnable effectively from different directories:

- Add a **base-path resolver** utility:
  - derive `repoBase` from `window.location.pathname`
  - compute links for root viewer and `/v2/` viewer from that base
- Add a visible `Switch Viewer` control in both pages.
- Keep links **relative** whenever possible.
- Document troubleshooting:
  - trailing slash behavior on GitHub Pages,
  - fork URL differences,
  - local file-open vs hosted behavior.

This resolves the practical navigation/path issue without changing simulation logic.
