Clinical Robot Competition v0.4.0

A 4-station clinical robot competition where doctor and nurse G1 humanoid robots coordinate to perform patient injection procedures. Each station runs independently with PPO reinforcement learning policies.

How the Simulation Works

  • Stations: 4 identical stations (A, B, C, D) in a 2x2 grid
  • Policy: All use PPO (MLP 64x64, tanh) with different seeds
  • State: Each station has a unique seed producing different behaviors
  • Reward: R = -0.3 × time + 0.5/(1+dist) + 0.2/(1+jerk)

Doctor (white coat, left of patient)

Reviews patient symptoms and toxicities on tablet before approving injection.

  • receive_chart → review_symptoms → assess_toxicity → approve_injection

Nurse (blue coat, right of patient)

Performs deltoid injection to patient's nearest arm with syringe.

  • prepare_syringe → approach_patient → position_needle → inject → hold_steady → withdraw

Competition Ranking

  • Time: Total elapsed seconds (doctor + nurse phases)
  • Accuracy: Euclidean distance of needle tip to target. Score = 1/(1+dist*100)
  • Winner: Fastest total time, tiebroken by accuracy
