Clinical Robot Competition Viewer

This viewer simulates a 4-station clinical robot competition where doctor and nurse robots coordinate to perform patient injection procedures.

Phases

  • Doctor: receive_chart → review_symptoms → assess_toxicity → approve_injection
  • Nurse: prepare_syringe → approach_patient → position_needle → inject → hold_steady → withdraw

Stations

  • A: seed=42, speed=1.0x
  • B: seed=137, speed=0.88x
  • C: seed=256, speed=1.08x
  • D: seed=512, speed=0.95x

Use the station buttons to focus on individual stations or view the overview. Upload a JSON config to customize station parameters.
